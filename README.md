# ♻️ Recicla+

O **Recicla+** é um aplicativo mobile desenvolvido com o objetivo de facilitar o descarte correto de resíduos.

A proposta é permitir que o usuário informe qual material deseja descartar e receba como resultado os pontos de coleta adequados mais próximos de sua localização.

## 📌 Sobre o projeto

Muitas pessoas possuem dúvidas sobre onde descartar corretamente materiais como:

- Pilhas
- Baterias
- Eletrônicos
- Lâmpadas
- Materiais recicláveis
- Outros resíduos que não devem ser descartados no lixo comum

O Recicla+ busca centralizar essas informações em uma aplicação simples e acessível.

## 🎯 Objetivo

Facilitar o acesso da população aos pontos de coleta e incentivar práticas de descarte correto e reciclagem.

Inicialmente, o projeto terá como área de atuação a cidade de **Sorocaba - SP**.

## ⚙️ Funcionalidades previstas

- Pesquisa de pontos de coleta por tipo de material
- Localização dos pontos de coleta próximos ao usuário
- Informações sobre os resíduos aceitos em cada local
- Visualização de endereço e localização
- Identificação do tipo de resíduo a partir da descrição do usuário
- Integração com recursos de Inteligência Artificial

Exemplo de utilização:

> "Tenho uma pilha para descartar."

A aplicação deverá identificar o tipo de resíduo e apresentar locais próximos que realizem a coleta desse material.
